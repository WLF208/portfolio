MPU6050 → I2C → 串级PID → PWM → 电机 · ESP8266 → Bootloader → Flash 回滚

  • 规划 Bootloader / 备份区 / 主应用区 Flash 布局，CRC16 帧校验 + CRC32 整包校验

基于 STM32F407 的实时采集系统，验证 ADC-DMA、FreeRTOS 任务调度与 LVGL 图形渲染链路。

STM32F407 FreeRTOS ADC-DMA LVGL SPI TFT FATFS
ADC+DMA硬件自动采样
多任务采集/预处理/渲染/按键
2 种边沿/软件触发
局部刷新LVGL 渲染优化
ADC → DMA → 预处理任务 → 队列/信号量 → LVGL → SPI TFT
